Recibe una notificación en este navegador

Esta página obtiene el token que Firebase necesita para enviarte una notificación de prueba.

1. Permite las notificaciones

Abre esta dirección en Chrome o Edge y pulsa el botón. Acepta «Permitir» cuando te lo pida el navegador.

Proyecto: Cargando…

Ya está configurada con la clave que proporcionaste. Puedes corregirla si cambias de proyecto.

Listo para empezar.

2. Copia el token FCM

El token identifica esta instalación del navegador. No es el JWT de inicio de sesión.

La página no registra este token en RutaSegura ni lo guarda en archivos del servidor.

3. Comprueba la recepción

Para una notificación emergente, deja esta pestaña en segundo plano y envía un mensaje de prueba desde Firebase al token obtenido.

Si la página está al frente, el mensaje aparecerá en el registro de abajo. El sistema operativo también debe permitir notificaciones del navegador.

  • Todavía no se recibieron mensajes.

Recibir un mensaje enviado desde Firebase verifica el navegador y FCM. El envío desde el backend se verifica después, por separado.
